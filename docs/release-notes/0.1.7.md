## English

Windows Stats 0.1.7 notices local AI models and talks to AI apps.

### New

- **Local AI sessions.** When a model runs in Ollama, llama.cpp, KoboldCpp or LocalAI, Windows Stats notices it within a few seconds and follows the session: highest and average CPU and GPU, highest video memory, memory and temperatures, and how long the runtime was busy. A card shows when it starts and a summary when it ends; Settings → **AI** lists recent sessions. The first time a model runs you are asked whether to follow sessions at all. Ollama counts only while it has a model loaded, not just because it is open. More programs can be added in `config.toml` (`ai_processes`).
- **Model names.** The model's name (for Ollama also its video memory) is asked from the runtime at its own local address (127.0.0.1). Nothing leaves the computer.
- **MCP for AI apps.** `WindowsStats.exe --mcp` is a read-only MCP server: LM Studio, Claude Desktop, VS Code and other MCP clients can read this computer's load (`system_overview`), the last two minutes (`recent_history`), the busiest programs (`top_processes`) and the AI sessions (`ai_sessions`), with local or cloud models. Settings → AI → **Copy the MCP setup** puts what the app needs on the clipboard. It opens no port; only `top_processes` returns program names, and its description warns that a cloud model's service receives them. See [docs/mcp.md](https://github.com/husodrn46/windows-stats/blob/main/docs/mcp.md).

Following sessions costs little: about 0.1% of one CPU core while waiting for a model.

### Updating

- **From 0.1.4 or newer:** Settings → About → **Check for updates**, then **Update to 0.1.7**.
- **From older versions:** download **WindowsStats-0.1.7-x64.zip**, extract the whole archive and run `Kur.cmd`. Your settings are kept.

## Türkçe

Windows Stats 0.1.7 yerel yapay zekâ modellerini fark ediyor ve yapay zekâ uygulamalarıyla konuşabiliyor.

### Yenilikler

- **Yerel yapay zekâ oturumları.** Ollama, llama.cpp, KoboldCpp ya da LocalAI ile bir model çalıştığında Windows Stats bunu birkaç saniye içinde fark eder ve oturumu takip eder: en yüksek ve ortalama işlemci ve ekran kartı kullanımı, en yüksek video belleği, bellek ve sıcaklıklar, çalışma zamanının ne kadar süre meşgul olduğu. Başlarken bir kart, bitince bir özet gösterir; Ayarlar → **Yapay zekâ** son oturumları listeler. Bir model ilk kez çalıştığında oturumların takip edilip edilmeyeceği sorulur. Ollama yalnızca açık olduğu için değil, model yüklüyken sayılır. Başka programlar `config.toml` içindeki `ai_processes` ile eklenebilir.
- **Model adları.** Modelin adı (Ollama'da video belleği de) çalışma zamanına kendi yerel adresinden (127.0.0.1) sorulur. Hiçbir şey bilgisayardan çıkmaz.
- **Yapay zekâ uygulamaları için MCP.** `WindowsStats.exe --mcp` salt okunur bir MCP sunucusudur: LM Studio, Claude Desktop, VS Code ve diğer MCP istemcileri bu bilgisayarın yükünü (`system_overview`), son iki dakikayı (`recent_history`), en yoğun programları (`top_processes`) ve yapay zekâ oturumlarını (`ai_sessions`) yerel ya da bulut modellerle okuyabilir. Ayarlar → Yapay zekâ → **MCP kurulum metnini kopyala**, uygulamanın ihtiyaç duyduğu metni panoya koyar. Port açmaz; program adlarını yalnızca `top_processes` verir ve açıklamasında bulut modelinin servisinin bu adları alacağı yazar. Ayrıntılar: [docs/mcp.md](https://github.com/husodrn46/windows-stats/blob/main/docs/mcp.md).

Oturumları takip etmenin bedeli küçük: model beklerken tek işlemci çekirdeğinin yaklaşık %0,1'i.

### Güncelleme

- **0.1.4 ve sonrasından:** Ayarlar → Hakkında → **Güncellemeleri denetle**, ardından **0.1.7 sürümüne güncelle**.
- **Daha eski sürümlerden:** **WindowsStats-0.1.7-x64.zip** dosyasını indirin, arşivin tamamını çıkarın ve `Kur.cmd` dosyasını çalıştırın. Ayarlarınız korunur.
