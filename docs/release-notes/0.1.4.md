## English

Windows Stats 0.1.4 can update itself from GitHub. Updating is optional and nothing is checked without your consent.

### New

- **Check for updates.** Settings → About → Check for updates asks GitHub for the latest release only when you click. When a newer version is out, **Update to x.y.z** downloads it, checks it against the size and SHA-256 digest GitHub reports, installs it in place and restarts Windows Stats. Your settings are kept and no administrator rights are needed. If the new version does not start, the running one stays.
- **Optional daily check.** On its first start, 0.1.4 asks once whether it may look for new versions by itself, at most once a day. A new version is announced once with a card in the corner; click it to open Settings → About. Change the answer any time in Settings → Privacy.
- **What a check sends.** One HTTPS request to api.github.com. GitHub sees your IP address and the Windows Stats version, as with any download. No settings, readings or identifiers are sent.

### Good to know

- Updating from inside the app works from 0.1.4 on. To get 0.1.4 itself, download it once more by hand.
- Only the installed copy (the one `Kur.cmd` set up) updates itself; a copy run from another folder offers the download page instead.
- Releases are still unsigned: the check confirms that you get exactly the archive published on GitHub, the same assurance as downloading it from the releases page.

### Install

Download **WindowsStats-0.1.4-x64.zip**, extract the whole archive and run `Kur.cmd`. Your settings are kept.

## Türkçe

Windows Stats 0.1.4 kendini GitHub'dan güncelleyebiliyor. Güncelleme isteğe bağlıdır; izniniz olmadan hiçbir denetim yapılmaz.

### Yenilikler

- **Güncellemeleri denetle.** Ayarlar → Hakkında → Güncellemeleri denetle, GitHub'a son sürümü yalnızca siz tıkladığınızda sorar. Yeni sürüm varsa **x.y.z sürümüne güncelle** düğmesi onu indirir, GitHub'ın bildirdiği boyut ve SHA-256 özetiyle karşılaştırır, aynı yere kurar ve Windows Stats'ı yeniden başlatır. Ayarlarınız korunur, yönetici izni gerekmez. Yeni sürüm açılmazsa çalışan sürüm yerinde kalır.
- **İsteğe bağlı günlük denetim.** 0.1.4 ilk açıldığında, yeni sürümleri kendiliğinden (günde en fazla bir kez) denetleyip denetlemeyeceğini bir kez sorar. Yeni sürüm köşedeki bir kartla bir kez duyurulur; karta tıklayınca Ayarlar → Hakkında açılır. Cevabı istediğiniz zaman Ayarlar → Gizlilik'ten değiştirebilirsiniz.
- **Denetim ne gönderir?** api.github.com'a tek bir HTTPS isteği. GitHub, her indirmede olduğu gibi IP adresinizi ve Windows Stats sürümünü görür. Ayar, ölçüm ya da kimlik bilgisi gönderilmez.

### Bilmekte yarar var

- Uygulama içinden güncelleme 0.1.4'ten itibaren çalışır. 0.1.4'ün kendisini bir kez daha elle indirmeniz gerekir.
- Yalnızca kurulu kopya (`Kur.cmd` ile kurulan) kendini günceller; başka bir klasörden çalışan kopya indirme sayfasını açar.
- Sürümler hâlâ imzasızdır: denetim, GitHub'da yayımlanan arşivin aynısını aldığınızı doğrular; bu, arşivi sürümler sayfasından indirmekle aynı güvencedir.

### Kurulum

**WindowsStats-0.1.4-x64.zip** dosyasını indirin, arşivin tamamını çıkarın ve `Kur.cmd` dosyasını çalıştırın. Ayarlarınız korunur.
