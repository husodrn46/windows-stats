## English

Windows Stats 0.1.3 shows the CPU and GPU temperatures side by side and no longer shows stale sensor readings. Thanks to @Warren-0 for the strip change (#6).

### New

- **CPU and GPU temperatures side by side.** When both report a temperature, the strip's temperature widget shows two columns, CPU and GPU, instead of only one. With only one of them, or only a disk temperature, it shows a single value as before. The release runs the optional sensor helper as a normal user, so many computers report no CPU temperature; they keep showing the GPU or SSD value.

### Fixed

- **No stale temperatures after the sensor helper stops.** If the optional sensor helper exits or its output fails, its last readings are discarded. Before, they could stay on screen and keep a temperature alert going as if they were live.

### Contributing

- Pull requests get a template that accepts English or Turkish, and new issues and pull requests are labelled automatically.

### Install

Download **WindowsStats-0.1.3-x64.zip**, extract the whole archive and run `Kur.cmd`. Your settings are kept.

## Türkçe

Windows Stats 0.1.3, işlemci ve ekran kartı sıcaklıklarını yan yana gösteriyor ve artık eski sensör okumalarını göstermiyor. Şerit değişikliği için @Warren-0'a teşekkürler (#6).

### Yenilikler

- **İşlemci ve ekran kartı sıcaklığı yan yana.** İkisi de sıcaklık bildirdiğinde şeritteki sıcaklık widget'ı tek değer yerine CPU ve GPU olmak üzere iki sütun gösteriyor. Yalnızca biri ya da yalnızca disk sıcaklığı varsa eskisi gibi tek değer görünüyor. Sürüm, isteğe bağlı sensör yardımcısını normal kullanıcı olarak çalıştırdığı için birçok bilgisayar işlemci sıcaklığı bildirmiyor; bu bilgisayarlarda GPU ya da SSD değeri görünmeye devam ediyor.

### Düzeltmeler

- **Sensör yardımcısı durunca eski sıcaklık kalmıyor.** İsteğe bağlı sensör yardımcısı kapanırsa ya da çıktısı bozulursa son okumaları siliniyor. Önceden bu değerler ekranda kalabiliyor ve sıcaklık uyarısını canlı veriymiş gibi sürdürebiliyordu.

### Katkı

- Pull request'ler için İngilizce ya da Türkçe doldurulabilen bir şablon eklendi; yeni issue ve pull request'ler otomatik etiketleniyor.

### Kurulum

**WindowsStats-0.1.3-x64.zip** dosyasını indirin, arşivin tamamını çıkarın ve `Kur.cmd` dosyasını çalıştırın. Ayarlarınız korunur.
