## English

Windows Stats 0.1.1 is a security and privacy update. **Everyone using 0.1.0 should update.**

### Security and privacy fixes

- **The sensor helper is never elevated any more.** In 0.1.0 the optional "run with administrator rights" switch started `sensors\WindowsStats.Sensors.exe` through a UAC prompt. That file lives in a folder your own account can write to, so any program running as you could replace it and receive administrator rights the next time you accepted the prompt. The switch is removed; an old `lhm_elevated = true` setting is ignored and dropped from `config.toml`. The helper's unused named-pipe output was removed as well.
- **Latency is measured only against the destination you choose.** When the chosen destination did not answer, 0.1.0 silently probed your network adapter's DNS servers and gateway and switched to TCP connections. Now only ICMP requests go to the destination you set, only while the network panel is open; if it does not answer, latency is shown as unavailable instead.

### What changes for you

- Readings that need the PawnIO driver with administrator rights (CPU package temperature, power, some fans and voltages) now show "not available" instead of a value. Readings that work with normal rights are unchanged.

### Install

Download **WindowsStats-0.1.1-x64.zip**, extract the whole archive over the old one (or into a new folder) and run `Kur.cmd`. Your settings are kept.

## Türkçe

Windows Stats 0.1.1 bir güvenlik ve gizlilik güncellemesidir. **0.1.0 kullanan herkesin güncellemesi önerilir.**

### Güvenlik ve gizlilik düzeltmeleri

- **Sensör yardımcısı artık hiç yönetici yetkisiyle çalıştırılmıyor.** 0.1.0'daki isteğe bağlı "yönetici olarak çalıştır" ayarı `sensors\WindowsStats.Sensors.exe` dosyasını UAC onayıyla başlatıyordu. Bu dosya kendi hesabınızın yazabildiği bir klasörde durduğu için, sizin adınıza çalışan herhangi bir program dosyayı değiştirip onayı verdiğiniz ilk açılışta yönetici yetkisi alabilirdi. Ayar kaldırıldı; eski `lhm_elevated = true` değeri yok sayılıyor ve `config.toml` dosyasından siliniyor. Yardımcının kullanılmayan named pipe çıkışı da kaldırıldı.
- **Gecikme yalnızca seçtiğiniz hedefe ölçülüyor.** 0.1.0, seçilen hedef yanıt vermediğinde ağ bağdaştırıcınızın DNS sunucularını ve ağ geçidini sessizce yokluyor, TCP bağlantısına geçiyordu. Artık yalnızca girdiğiniz hedefe ve yalnızca ağ paneli açıkken ICMP isteği gidiyor; hedef yanıt vermezse gecikme "kullanılamıyor" görünüyor.

### Sizin için ne değişiyor

- PawnIO sürücüsü ve yönetici yetkisi gerektiren okumalar (CPU paket sıcaklığı, güç, bazı fan ve voltajlar) artık değer yerine "kullanılamıyor" görünüyor. Normal yetkiyle çalışan okumalar değişmedi.

### Kurulum

**WindowsStats-0.1.1-x64.zip** dosyasını indirin, arşivin tamamını çıkarın ve `Kur.cmd` dosyasını çalıştırın. Ayarlarınız korunur.
