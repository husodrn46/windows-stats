## English

Windows Stats 0.1.2 makes the taskbar text easier to read on high-resolution screens. Thanks to @EfeTheCaptain for the request (#3).

### New

- **Font size from 80% to 200%.** Settings → Appearance → Font size now has a − / + control instead of four presets, and the right-click menu offers 150%, 175% and 200%. Above 130% the widgets use more of the taskbar height so rows do not overlap.
- **Font choice.** Settings → Appearance → Font cycles through common fonts installed on your computer (Segoe UI, Bahnschrift, Arial, Calibri, Cascadia Mono, Consolas, Tahoma, Trebuchet MS, Verdana). Any other installed font can be set with `font_family = "Name"` in `config.toml`. If the font is not installed, the default is used.

### Install

Download **WindowsStats-0.1.2-x64.zip**, extract the whole archive and run `Kur.cmd`. Your settings are kept.

## Türkçe

Windows Stats 0.1.2, yüksek çözünürlüklü ekranlarda görev çubuğu yazılarını daha okunur hâle getiriyor. İstek için @EfeTheCaptain'a teşekkürler (#3).

### Yenilikler

- **Yazı boyutu %80 ile %200 arası.** Ayarlar → Görünüm → Yazı boyutu artık dört hazır seçenek yerine − / + düğmeleriyle ayarlanıyor; sağ tık menüsüne %150, %175 ve %200 eklendi. %130'un üstünde widget'lar görev çubuğu yüksekliğinin daha fazlasını kullanıyor, böylece satırlar üst üste binmiyor.
- **Yazı tipi seçimi.** Ayarlar → Görünüm → Yazı tipi, bilgisayarınızda kurulu yaygın yazı tipleri arasında geçiş yapıyor (Segoe UI, Bahnschrift, Arial, Calibri, Cascadia Mono, Consolas, Tahoma, Trebuchet MS, Verdana). Kurulu başka bir yazı tipi `config.toml` içinde `font_family = "Ad"` ile seçilebilir. Yazı tipi kurulu değilse varsayılan kullanılıyor.

### Kurulum

**WindowsStats-0.1.2-x64.zip** dosyasını indirin, arşivin tamamını çıkarın ve `Kur.cmd` dosyasını çalıştırın. Ayarlarınız korunur.
