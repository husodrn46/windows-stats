# Windows Stats website

Static product site for the open-source Windows Stats project. Application source and releases are managed separately on the default branch.

## Cloudflare Pages
- Repository: `husodrn46/windows-stats`
- Production branch: `website`
- Framework preset: **None**
- Build command: leave empty
- Output directory: `website`
- Root directory: leave empty (repository root)
- No environment variables or credentials are required to build or run the site.

Open `index.html` through a local static server to test the Turkish/English toggle and the screenshot gallery. Download and contribution links point to the official GitHub project. Screenshots are public Windows Stats repository captures under `docs/images/`, converted to WebP. Update the version label and primary ZIP link together when promoting a new release.
